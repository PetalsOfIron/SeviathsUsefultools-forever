# SeviathsUsefulTools for WoW Forever

The Forever version of SeviathsUsefulTools (made from the retail version).

Install: copy this folder to `World of Warcraft/_forever_/Interface/AddOns/SeviathsUsefulTools`, and copy every folder inside `lod/` next to it in
`AddOns` (they are the load-on-demand data folders: items, drops, transmog and monsters of Classic).

See `FOREVER-PORT.md` for what is done and what is not.
